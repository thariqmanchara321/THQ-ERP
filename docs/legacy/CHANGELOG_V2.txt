- Added Business Templates editor.
- Added Subscription Plans editor with module entitlements and usage-limit metadata.

CLIENT APP

- Added tenant Business Settings screen.
- Added industry-pack workspace navigation for Restaurant, Workshop, Healthcare, Pharmacy and Lab.
- Added POS/Settings/industry module icons/routes.

BACKEND
- Preserved additive V1 migrations 001-005.

- Seeded POS and industry modules/templates/plans.
- Added protected platform/admin/client RPCs.
- Added dependency- and subscription-aware tenant-module update RPC.
- Existing tenants receive Settings module; no subscription is forced on existing tenants.

NOT INCLUDED AS COMPLETED DOMAIN WORKFLOWS
- Restaurant KOT/table/order database workflows
- Workshop job-card database workflow

- Lab sample/result records
