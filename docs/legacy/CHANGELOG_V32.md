# Flexi ERP V3.2

V3.2 is the final branch/terminal/POS usability and access-control pass requested after V3.1.

Highlights: terminal module profiles, terminal invoice sequences, atomic location-scoped financial creates, store/user access levels, Client global/menu search, automatic SKU suggestion, friendly entity IDs, redesigned multi-step POS, POS category/sort/quick cash, collapsible navigation, Client store scope and systems directory, Client owner-managed team access, Admin Home navigation and broad UI polish.


Final security pass: Production runs, Transport vehicles/jobs, and Restaurant tables/orders/KOT/status/billing are now server-side store scoped. Restaurant POS calls also validate the registered terminal and its restaurant module entitlement.
